# 朋友安装指南：手动安装版

适用情况：朋友收到 `friends-unpacked.zip` 文件，希望立即试用，不等待 Chrome 商店审核。

整个过程大约需要 2 分钟。

正式下载地址：<https://github.com/zhijinallin/wechat-article-exporter/releases/latest>

在最新版本的 Assets 中，下载文件名包含 `friends-unpacked.zip` 的文件。

## 第一步：解压 ZIP

双击收到的 ZIP 文件。解压后会得到一个类似下面的文件夹：

```text
wechat-article-exporter-v0.1.0
```

把这个文件夹放在一个不会随手删除或移动的位置，例如“文稿”或“应用工具”。不要直接从 ZIP 内部打开。

## 第二步：打开扩展程序页面

在 Chrome 地址栏输入：

```text
chrome://extensions/
```

按回车。

## 第三步：加载插件

1. 打开页面右上角的“开发者模式”；
2. 点击左上角“加载未打包的扩展程序”；
3. 选择刚才解压得到的整个文件夹；
4. 看到“微信文章本地导出器”卡片后，说明安装完成。

如果 Chrome 提示找不到 `manifest.json`，通常是选错了外层目录。请选择打开后能直接看到 `manifest.json` 的那一层文件夹。

## 第四步：固定到工具栏

1. 点击 Chrome 右上角的拼图图标；
2. 找到“微信文章本地导出器”；
3. 点击旁边的固定图标。

## 第五步：试用

1. 打开一篇可以正常阅读的微信公众号文章；
2. 点击“微信文章本地导出器”；
3. 看到文章标题和“已识别正文”提示后，任选一个导出按钮；
4. 确认文件能正常下载和打开。

详细用法见[使用说明](USER-GUIDE.md)。

## 如何升级

收到新版 ZIP 后：

1. 解压到一个新的文件夹；
2. 打开 `chrome://extensions/`；
3. 在旧版插件卡片上点击“移除”；
4. 点击“加载未打包的扩展程序”，选择新版文件夹；
5. 确认可以使用后，再删除旧版文件夹。

## 安全提醒

- 只接收项目所有者或可信朋友发来的 ZIP；
- 不要安装来历不明、被重新修改过的版本；
- 可以使用发行包附带的 `SHA256SUMS.txt` 核对文件是否完整；
- 手动安装版不会自动升级。

## 如何卸载

打开 `chrome://extensions/`，找到插件后点击“移除”。卸载插件不会删除你已经导出的 HTML 或 Markdown 文件。
