# 使用说明

这份说明写给第一次使用插件的人，不需要技术背景。

## 使用前

1. 使用 Google Chrome 打开一篇可以正常阅读的微信公众号文章；
2. 等待文章正文和图片加载完成；
3. 点击浏览器右上角的扩展程序图标；
4. 找到“微信文章本地导出器”，建议把它固定在工具栏。

## 三个按钮怎么选

### 下载完整 HTML

相当于把文章做成一份可以独立打开的网页副本。插件会尽量把正文图片放进同一个文件。

适合：

- 离线阅读；
- 保留较完整的原文样式；
- 上传给支持 HTML 的 AI 工具分析。

### 下载 Markdown

相当于把文章整理成一份干净的电子稿。文件较小，排版也更简单。

适合：

- 导入知识库；
- 全文检索；
- 使用文本编辑器继续整理；
- 交给 AI 阅读。

Markdown 中的图片通常仍然使用原来的微信图片地址。以后原地址失效时，图片可能无法显示。

### 复制 Markdown

内容不会生成文件，而是复制到电脑剪贴板。之后可以直接粘贴到 AI 对话框、笔记软件或文档中。

## 导出的文件在哪里

文件通常保存在 Chrome 的默认“下载”目录。如果浏览器设置为“每次询问保存位置”，Chrome 会让你选择目录。

## 常见问题

### 提示“当前页面不是微信公众号文章”

请确认地址以 `https://mp.weixin.qq.com/s` 开头，并且当前选中的标签页就是文章页面。

### 提示“未识别到微信公众号正文”

先刷新文章并等待正文完全出现，再打开插件。失效、删除、需要验证或无法正常阅读的文章不能导出。

### HTML 中有少量图片没有保存进去

插件只会下载微信常用图片域名中的正文图片。非微信图片、超大图片或下载失败的图片会保留原地址或被跳过。

### 视频和音频没有一起保存

当前版本不会打包视频或音频，只会保留提示文字或原始链接。

### 插件突然不见了

如果是手动安装版，请检查原来的插件文件夹是否被移动或删除，然后按照[朋友安装指南](FRIEND-INSTALL.md)重新加载。

## 隐私

插件只在你点击后处理当前文章，不会把文章上传给开发者。完整说明见[隐私政策](../PRIVACY.md)。
