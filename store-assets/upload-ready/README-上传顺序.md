# Chrome 商店图片上传顺序

在 Chrome Web Store Developer Dashboard 的“图片资源”页面，依次选择本文件夹中的图片：

1. **商店图标** → `01-store-icon-128x128.png`
2. **屏幕截图** → `02-screenshot-1280x800.png`
3. **小型宣传图块** → `03-small-promo-440x280.png`
4. **顶部宣传图块** → `04-marquee-1400x560-optional.png`（可选，但已经准备好）

“全球通用的宣传视频”可以留空。

前三张上传后，点击页面右上角“保存草稿”。如果仍显示不能提交，继续检查商品详情、隐私权规范和发布范围页面的必填字段。
