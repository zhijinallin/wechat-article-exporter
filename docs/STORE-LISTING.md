# Chrome 商店上架文案

以下内容可复制到 Chrome Web Store Developer Dashboard。首次提交后，应以后台实际字段名称为准逐项核对。

## 基本信息

**名称**

```text
微信文章本地导出器
```

**简短说明**

```text
将当前打开的微信公众号文章导出为完整 HTML 或 Markdown；内容只在本机处理。
```

**分类**

```text
Productivity / 生产力工具
```

**默认语言**

```text
中文（简体）
```

## 详细说明

```text
一键保存当前打开的微信公众号文章。

主要功能：
• 下载完整 HTML：尽量把正文图片放进同一个文件，方便离线阅读、归档和 AI 分析；
• 下载 Markdown：生成轻量文本，方便知识库、检索和继续编辑；
• 复制 Markdown：直接粘贴到 AI、笔记或文档中。

隐私保护：
• 只有用户主动点击插件时，才读取当前标签页；
• 文章内容只在用户自己的电脑中处理；
• 不上传文章，不建立账号，不含广告和统计分析；
• 不读取 Cookie、密码或完整浏览历史。

使用边界：
本扩展只能导出用户已经能够正常阅读的文章，不绕过登录、付费、验证码、删除或其他访问限制。视频和音频不会打包。

本扩展与腾讯、微信或微信公众平台没有隶属、授权或官方合作关系。
```

## 单一用途

```text
在用户主动点击后，把当前打开且可正常阅读的微信公众号文章导出为本地 HTML 或 Markdown 文件。
```

## 权限说明

**activeTab**

```text
仅在用户点击扩展时临时读取当前标签页，用于确认当前页面是微信公众号文章并提取用户要求导出的内容。
```

**scripting**

```text
在用户当前打开的文章页面运行正文提取函数，读取标题、作者、发布时间、正文和图片地址。不会在后台持续运行。
```

**https://mmbiz.qpic.cn/*** 和 **https://mmbiz.qlogo.cn/***

```text
获取当前文章本来引用的微信正文图片，把图片嵌入用户下载的完整 HTML 文件。请求不携带用户凭证，图片不会发送给开发者。
```

## 隐私问卷建议答案

| 问题 | 建议填写 |
|---|---|
| 是否处理网站内容 | 是，只处理用户当前要求导出的文章 |
| 是否传输给开发者或第三方 | 否 |
| 是否出售用户数据 | 否 |
| 是否用于广告或信用评估 | 否 |
| 是否包含远程代码 | 否，全部执行代码随扩展一起提供 |
| 是否有账号或登录 | 否 |
| 是否使用统计分析 | 否 |

如果后台问题的表述发生变化，原则是如实说明“处理网站内容，但只在本机为了导出而处理，不传给开发者”。不要为了看起来权限更少而选择“完全不处理网站内容”。

## 审核人员测试步骤

```text
1. 使用 Chrome 打开一篇公开可访问的 https://mp.weixin.qq.com/s/... 文章。
2. 等待正文和图片加载完成。
3. 点击工具栏中的“微信文章本地导出器”。
4. 弹窗应显示文章标题、公众号名称和识别到的正文字符数、图片数。
5. 点击“下载 Markdown”，应下载一个 .md 文件。
6. 再次打开弹窗并点击“下载完整 HTML”，应下载一个 .html 文件，正文图片会尽量内嵌。
7. 整个过程不要求登录本扩展，也不会把文章发送到开发者服务器。
```

正式提交时，建议在测试说明开头补充一条当时可访问的公开微信公众号文章链接，减少审核人员寻找测试文章的时间。
