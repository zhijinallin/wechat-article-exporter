# Chrome 商店上架文案

以下内容可复制到 Chrome Web Store Developer Dashboard。首次提交后，应以后台实际字段名称为准逐项核对。

本文件只保存“微信文章本地导出器”的具体文案。通用方法见 [Chrome Web Store 上架通用指南](WEB-STORE-PUBLISH-GENERAL.md)，v0.1.0 实际提交状态和素材见 [首次提交记录](submissions/2026-09-01-v0.1.0.md)。

## 发布账号联系邮箱

联系邮箱属于发布者账号设置，不在单个扩展的“商品详情”或“隐私权”页面中。

1. 打开 Chrome Web Store Developer Dashboard 首页：<https://chrome.google.com/webstore/devconsole/>；
2. 点击网页左上角、Chrome Web Store 标志旁边的三横线总菜单；
3. 选择“账号”“账户”或“设置”（英文界面为 `Account` 或 `Settings`）；
4. 在“联系邮箱”区域点击“添加邮箱”，输入一个能正常收信的邮箱并保存；
5. 点击“验证邮箱”或“发送验证邮件”；
6. 在该邮箱中打开 Chrome Web Store 发来的邮件并点击验证链接；
7. 返回开发者后台刷新页面，确认邮箱显示为“已验证”。

网页右上角显示的发布者登录账号不等于已经添加并验证联系邮箱。两者可以使用同一个邮箱，但仍需完成上述添加和验证步骤。

## 详细说明

```text
一键保存当前打开的微信公众号文章。

主要功能：
• 下载完整 HTML：尽量把正文图片放进同一个文件，方便离线阅读、归档和 AI 分析；
• 下载 Markdown：生成轻量文本，方便知识库、检索和继续编辑；
• 复制 Markdown：直接粘贴到 AI、笔记或文档中。

隐私保护：
• 只有用户主动点击插件时，才读取当前标签页；
• 文章内容只在用户自己的电脑中处理；
• 不上传文章，不建立账号，不含广告和统计分析；
• 不读取 Cookie、密码或完整浏览历史。

使用边界：
本扩展只能导出用户已经能够正常阅读的文章，不绕过登录、付费、验证码、删除或其他访问限制。视频和音频不会打包。

本扩展与腾讯、微信或微信公众平台没有隶属、授权或官方合作关系。
```

## 单一用途

```text
在用户主动点击后，把当前打开且可正常阅读的微信公众号文章导出为本地 HTML 或 Markdown 文件。
```

## 权限说明

**activeTab**

```text
仅在用户点击扩展时临时读取当前标签页，用于确认当前页面是微信公众号文章并提取用户要求导出的内容。
```

**scripting**

```text
在用户当前打开的文章页面运行正文提取函数，读取标题、作者、发布时间、正文和图片地址。不会在后台持续运行。
```

**https://mmbiz.qpic.cn/*** 和 **https://mmbiz.qlogo.cn/***

```text
仅在用户点击“下载完整 HTML”时，从当前微信公众号文章引用的 mmbiz.qpic.cn 和 mmbiz.qlogo.cn 获取正文图片，并将图片嵌入用户下载的单个 HTML 文件，以便离线查看。权限仅限这两个微信图片域名；请求不携带 Cookie 或其他用户凭证，图片不会上传给开发者或保存到开发者服务器。
```

后台的“您正在使用远程代码吗？”选择：

```text
不，我并未使用远程代码
```

插件执行的 JavaScript 全部包含在上传的扩展程序包中。从微信图片域名获取的只是图片数据，不是 JavaScript 或 WebAssembly，因此不属于远程代码。选择“否”后，下面灰色的“理由”输入框不需要填写。

## 隐私问卷建议答案

| 问题 | 建议填写 |
|---|---|
| 是否处理网站内容 | 是，只处理用户当前要求导出的文章 |
| 是否传输给开发者或第三方 | 不传给开发者；仅在下载完整 HTML 时，通过 HTTPS 向文章原本引用的两个微信图片域名请求图片 |
| 是否出售用户数据 | 否 |
| 是否用于广告或信用评估 | 否 |
| 是否包含远程代码 | 否，全部执行代码随扩展一起提供 |
| 是否有账号或登录 | 否 |
| 是否使用统计分析 | 否 |

如果后台问题的表述发生变化，原则是如实说明“处理网站内容，但只在本机为了导出而处理，不传给开发者”。不要为了看起来权限更少而选择“完全不处理网站内容”。

### 数据使用勾选表

在“目前或未来您打算向用户收集哪些用户数据？”中，勾选：

```text
网络记录
网站内容
```

以下项目均不勾选：

```text
个人身份信息
健康信息
财务和付款信息
身份验证信息
个人通讯
位置
用户活动
```

原因：插件处理用户主动选择导出的当前文章文字、图片、超链接和文章元数据，因此属于“网站内容”；同时读取并写入当前文章的标题和原文网址，因此按 Chrome 对域名和 URL 的定义披露为“网络记录”。它不会读取或建立完整浏览历史列表，也不会在后台监控其他页面。文章中出现的作者姓名属于所选网页内容；插件不会另行收集扩展使用者的姓名、邮箱或账号资料，也不会记录、分析或上传用户的点击、滚动和键盘操作。

在“我确认下列披露信息均属实”中，三项全部勾选：

```text
我不会出于已获批准的用途之外的用途向第三方出售或传输用户数据
我不会为实现与产品的单一用途无关的目的而使用或转移用户数据
我不会为确定信用度或放贷目的而使用或转移用户数据
```

即使文章数据只在用户设备上处理，Chrome 仍要求披露“网站内容”和当前文章 URL 所涉及的“网络记录”。从两个微信图片域名读取正文图片是完成用户主动选择的“完整 HTML”导出所必需的功能，不是出售数据或用于其他目的。

## 审核人员测试步骤

```text
1. 使用 Chrome 打开一篇公开可访问的 https://mp.weixin.qq.com/s/... 文章。
2. 等待正文和图片加载完成。
3. 点击工具栏中的“微信文章本地导出器”。
4. 弹窗应显示文章标题、公众号名称和识别到的正文字符数、图片数。
5. 点击“下载 Markdown”，应下载一个 .md 文件。
6. 再次打开弹窗并点击“下载完整 HTML”，应下载一个 .html 文件，正文图片会尽量内嵌。
7. 整个过程不要求登录本扩展，也不会把文章发送到开发者服务器。
```

正式提交时，建议在测试说明开头补充一条当时可访问的公开微信公众号文章链接，减少审核人员寻找测试文章的时间。
